# Ethics Statement

This project analyses written social-media text for an academic classification task. The analysis concerns dataset labels and observable textual features, not private psychological states.

## Data handling
- Use only data whose source terms and licence permit the intended research use.
- Do not publish usernames, profile URLs, or unnecessary personal identifiers.
- Avoid attempting to identify authors or link posts to individuals.
- Review the source dataset's redistribution conditions before publishing raw text in a public repository.

## Interpretation safeguards
- Do not describe proxy features as direct measurements of pitch, intonation, or spoken prosody.
- Do not equate sentiment labels with emotion or communicative intent.
- Treat Ghanaian language varieties as diverse; spelling and code-switching are not errors by default.
- Acknowledge that emojis, particles, elongation, punctuation, and capitalization are context-dependent.
- Do not use predictions to make consequential decisions about individuals.

## Reporting
Publish preprocessing choices, dataset provenance, evaluation partitions, metrics, and known limitations. Distinguish completed experiments from planned analyses.
